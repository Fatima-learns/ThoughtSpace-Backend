
# ThoughtSpace Backend

Backend API for **ThoughtSpace**, a community-based platform where users can share thoughts, experiences, advice, lessons, opinions, questions, and motivation.

The backend provides authentication, user management, database connectivity, and API endpoints required by the frontend.

## Features

- User registration
- User login
- Authentication using JWT
- Access token generation
- Refresh token generation
- Refresh token stored in an HttpOnly cookie
- Protected authentication endpoint
- Current user information endpoint
- MongoDB database integration
- Password hashing using bcrypt
- Express.js API routes

## Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcryptjs
- cookie-parser
- dotenv
